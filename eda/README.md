# EDA Playground bundles

Single-file copies for pasting into [EDA Playground](https://www.edaplayground.com/):

- `aes128_rtl.sv`, all of `rtl/` concatenated, for the **design** pane.
- `aes128_uvm_tb.sv`, the `tb/uvm/` environment concatenated, for the **testbench** pane.

They're copies of `../rtl/` and `../tb/uvm/`. Make changes there first, then
copy them over.
